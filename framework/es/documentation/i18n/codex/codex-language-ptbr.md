# Codex: Guía para Traducir al Portugués Brasileño

> **Prefijo:** `codex-` | **Tipo:** Manual de Referencia | **Alcance:** Convenciones y orientaciones para traducción técnica al pt-BR

## Visión General

Este Codex es la guía práctica para traducir documentación técnica **al Portugués Brasileño (pt-BR)**. Complementa la `lex-language-ptbr` (reglas obligatorias) con orientaciones, ejemplos y tablas de referencia.

## Contexto

- **Dominio:** Traducción técnica al pt-BR
- **Público objetivo:** `warrior-translator` y agentes que traduzcan al pt-BR
- **Actualización:** siempre que se identifiquen nuevas convenciones para pt-BR

## Contenido

### Convenciones de Escritura Técnica en pt-BR

1. **Voz activa** es preferible a la voz pasiva
2. **Frases objetivas** — evitar rodeos y construcciones rebuscadas
3. **Párrafos cortos** — facilitar la lectura en pantalla
4. **Consistencia terminológica** — mantener el mismo término para el mismo concepto

### Patrones de Formalización

| Contexto | Patrón correcto | Patrón incorrecto |
|----------|-----------------|-------------------|
| Obligatoriedad | "O agente **DEVE**..." | "O agente tem que..." |
| Necesidad | "É necessário..." | "Precisa..." |
| Recomendación | "Recomenda-se..." | "É bom que..." |
| Instrucción directa | "Crie o arquivo..." | "Você poderia criar o arquivo..." |

### Errores Comunes

1. **"Deletar" vs "Excluir"** — Preferir "excluir" en contexto formal
2. **"Setar" vs "Configurar"** — Preferir "configurar"
3. **"Rodar" vs "Executar"** — Preferir "executar" en contexto formal
4. **"Checar" vs "Verificar"** — Preferir "verificar"
