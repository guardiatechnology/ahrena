# Codex: Guia para Traduzir para Espanhol

> **Prefixo:** `codex-` | **Tipo:** Manual de Referência | **Escopo:** Convenções e orientações para tradução técnica para espanhol (es)

## Visão Geral

Este Codex é o guia prático para traduzir documentação técnica **para Espanhol neutro (es)**. Complementa a `lex-language-es` (regras obrigatórias) com orientações, exemplos e tabelas de referência.

## Conteúdo

### Convenções de Escritura Técnica em Espanhol

1. **Voz impessoal** é preferida em documentação técnica: "Se debe configurar..." em vez de "Debes configurar..."
2. **Frases claras e diretas** — evitar construções complexas
3. **Consistência de registro** — manter o mesmo nível de formalidade ao longo do documento
4. **Sinais de abertura** — sempre usar ¿ e ¡ no início de interrogações e exclamações

### Padrões de Formalização

| Contexto | Padrão correto (es) | Padrão incorreto (es) |
|----------|---------------------|----------------------|
| Obrigatoriedade | "Se **DEBE** configurar..." | "Tienes que configurar..." |
| Necessidade | "Es necesario..." | "Hace falta..." (coloquial) |
| Recomendação | "Se recomienda..." | "Estaría bien que..." |
| Proibição | "**NO SE DEBE**..." | "No hay que..." |

### Erros Comuns ao Traduzir de pt-BR para es

1. **Manter a estrutura do pt-BR** — Espanhol tem ordem de palavras diferente em alguns contextos
2. **Falsos cognatos** — A tabela acima é essencial
3. **Pontuação** — Não esquecer ¿ e ¡ de abertura
4. **"Muito" vs "Mucho/Muy"** — Saber quando usar cada forma
5. **Gerúndio** — Espanhol usa menos gerúndio que pt-BR

### Erros Comuns ao Traduzir de en para es

1. **Voz passiva excessiva** — Inglês usa mais voz passiva; em espanhol, preferir voz ativa ou impessoal
2. **Ordem sujeito-verbo** — Espanhol é mais flexível que inglês
3. **"Actual"** (en = real) ≠ "actual" (es = atual/current)
4. **"Sensible"** (en = sensato) ≠ "sensible" (es = sensível)
