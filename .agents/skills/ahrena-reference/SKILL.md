# Ahrena reference routing

1. Read the managed Ahrena section in `AGENTS.md` and `.ahrena/.directives`.
2. Search `.codex/docs/lex/` for applicable laws and `.codex/docs/codex/` for supporting manuals.
3. Read only the relevant files. Treat Lexis as mandatory and Ahrena Codex documents as guidance.
4. State any human gate or authorization boundary before an external write.
5. Apply the selected guidance and cite the local source paths in the handoff.
