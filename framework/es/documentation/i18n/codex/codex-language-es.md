# Codex: Guía para Traducir al Español

> **Prefijo:** `codex-` | **Tipo:** Manual de Referencia | **Alcance:** Convenciones y orientaciones para traducción técnica al español (es)

## Visión General

Este Codex es la guía práctica para traducir documentación técnica **al Español neutro (es)**. Complementa la `lex-language-es` (reglas obligatorias) con orientaciones, ejemplos y tablas de referencia.

## Contexto

- **Dominio:** Traducción técnica al español
- **Público objetivo:** `warrior-translator` y agentes que traduzcan al español
- **Actualización:** siempre que se identifiquen nuevas convenciones para español

## Contenido

### Convenciones de Escritura Técnica en Español

1. **Voz impersonal** es preferida en documentación técnica: "Se debe configurar..." en vez de "Debes configurar..."
2. **Frases claras y directas** — evitar construcciones complejas
3. **Consistencia de registro** — mantener el mismo nivel de formalidad
4. **Signos de apertura** — siempre usar ¿ y ¡ al inicio de interrogaciones y exclamaciones

### Patrones de Formalización

| Contexto | Patrón correcto | Patrón incorrecto |
|----------|-----------------|-------------------|
| Obligatoriedad | "Se **DEBE** configurar..." | "Tienes que configurar..." |
| Necesidad | "Es necesario..." | "Hace falta..." (coloquial) |
| Recomendación | "Se recomienda..." | "Estaría bien que..." |
| Prohibición | "**NO SE DEBE**..." | "No hay que..." |

### Errores Comunes al Traducir desde pt-BR

1. **Mantener estructura del pt-BR** — El español tiene un orden de palabras diferente en algunos contextos
2. **Falsos cognatos** — La tabla anterior es esencial
3. **Puntuación** — No olvidar ¿ y ¡ de apertura
4. **Gerundio** — El español usa menos gerundio que el pt-BR

### Errores Comunes al Traducir desde en

1. **Voz pasiva excesiva** — El inglés usa más voz pasiva; en español, preferir voz activa o impersonal
2. **"Actual"** (en = real) ≠ "actual" (es = current)
3. **"Sensible"** (en = sensato) ≠ "sensible" (es = sensitivo)
4. **"Eventually"** (en = finalmente) ≠ "eventualmente" (es = posiblemente)
