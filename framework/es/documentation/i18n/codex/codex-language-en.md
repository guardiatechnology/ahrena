# Codex: Guía para Traducir al Inglés

> **Prefijo:** `codex-` | **Tipo:** Manual de Referencia | **Alcance:** Convenciones y orientaciones para traducción técnica al inglés (en)

## Visión General

Este Codex es la guía práctica para traducir documentación técnica **al Inglés (en)**. Complementa la `lex-language-en` (reglas obligatorias) con orientaciones, ejemplos y tablas de referencia.

## Contexto

- **Dominio:** Traducción técnica al inglés
- **Público objetivo:** `warrior-translator` y agentes que traduzcan al inglés
- **Actualización:** siempre que se identifiquen nuevas convenciones para inglés

## Contenido

### Convenciones de Technical Writing en Inglés

1. **Imperative mood** para instrucciones: "Run the command", "Create the file"
2. **Active voice** siempre que sea posible
3. **Present tense** como estándar
4. **One idea per sentence** — frases cortas y enfocadas

### Elecciones de Vocabulario

| Preferir | Evitar | Motivo |
|----------|--------|--------|
| Palabras simples | Sinónimos complejos | Claridad |
| Términos específicos | Lenguaje vago | Precisión |
| "Run X" | "You should run X" | Concisión |
| "do not" | "don't" | Formalidad |

### Errores Comunes al Traducir desde pt-BR

| Error | Corrección | Ejemplo |
|-------|-----------|---------|
| "realize" (≠ realizar) | "perform" | "Perform the task" |
| "actually" (≠ atualmente) | "currently" | "Currently active" |
| "pretend" (≠ pretender) | "intend" | "Intend to create" |
| "resume" (≠ resumir) | "summarize" | "Summarize the results" |

### Errores Comunes al Traducir desde es

| Error | Corrección | Ejemplo |
|-------|-----------|---------|
| "sensible" (≠ sensible) | "sensitive" | "Sensitive data" |
| "actual" (≠ actual) | "current" | "Current version" |
| "eventual" (≠ eventual) | "possible" | "A possible error" |
